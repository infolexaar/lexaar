# Настройка MCP для Figma

## Шаг 1: Включить MCP сервер в Figma Desktop App

1. Откройте **Figma Desktop App** (не браузерную версию)
2. Откройте ваш дизайн-файл
3. Переключитесь в **Dev Mode** (нажмите `Shift + D` или переключатель внизу)
4. В правой боковой панели найдите раздел **"MCP server"**
5. Нажмите **"Enable desktop MCP server"**
6. Скопируйте URL сервера: `http://127.0.0.1:3845/mcp`

## Шаг 2: Настроить MCP в Cursor

1. Откройте Cursor Settings:

   - `Cmd + ,` (macOS) или `Ctrl + ,` (Windows)
   - Или через меню: Cursor → Settings

2. Найдите раздел **"MCP"** или **"Model Context Protocol"**

3. Добавьте новый MCP сервер:

   ```json
   {
     "mcpServers": {
       "figma-desktop": {
         "url": "http://127.0.0.1:3845/mcp"
       }
     }
   }
   ```

4. Сохраните настройки

## Шаг 3: Проверка подключения

После настройки я смогу:

- ✅ Читать структуру компонентов из Figma
- ✅ Получать точные размеры и стили
- ✅ Скачивать изображения напрямую из Figma
- ✅ Структурировать файлы по папкам
- ✅ Автоматически создавать компоненты на основе дизайна

## Важно

- Figma Desktop App должен быть запущен
- MCP сервер должен быть включен в Dev Mode
- URL сервера: `http://127.0.0.1:3845/mcp`
